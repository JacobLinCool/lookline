# 2026 梅竹黑客松 × 聚陽實業｜題目說明

> **一句話，讀懂消費者要什麼**  
> 賽前工作坊 · 題目說明｜主講：資訊處

---

## 核心題意

前段聚焦在設計師如何從社群趨勢找靈感，將**趨勢變成商品**；速度與「訊號轉商品」是關鍵。

但整條鏈最前端、也最難接住的訊號，是：

> **消費者到底想要什麼？**

購物正在從「**搜尋關鍵字**」走向「**說一句話**」。

---

## 整體架構：從趨勢到消費者，再回到設計

### 製造端

1. **趨勢與參考來源**
   - TikTok
   - Pinterest
   - 秀場
   - KOL

2. **設計師發想・選款**
   - 趨勢 → 款式・色彩・材料

3. **打樣・材料・生產**
   - 目標是最快把訊號變成商品

4. **商品庫**
   - 可購買的真實商品

### 消費端

- 核心問題：**消費者在想什麼？**
- 要接住的是**消費者意圖與偏好**
- 這些資訊是製造端所缺少的**市場前端訊號**
- 將訊號回饋至設計、開款與生產後，可把原本的單向流程變成**愈跑愈準的閉環**

**概念流程：**

`趨勢 → 設計 → 生產 → 商品庫 → 消費者意圖 / 偏好 → 回饋設計・開款・生產`

## Engine 01｜需求理解

### 把「一句話」變成「結構化意圖」

**技術方向（僅供參考，不限於此）：**

- Slot filling
- 資訊抽取（NER）
- LLM 結構化輸出
  - JSON
  - Tool use
- 對話狀態管理

**重點：**

> 真本事在「**抽得準 + 接得住模糊**」，而不是把字面照抄。

---

## Engine 02｜可解釋性的 AI

**技術方向（僅供參考，不限於此）：**

- 內容式推薦＋排序
- 影像 / 文字 embedding
  - 例如 FashionCLIP
- 穿搭相容性
  - 例如 Polyvore
- 預算等約束求解

**難點：**

> 在約束條件下維持推薦品質，而不是隨便湊出結果。

---

## Engine 03｜偏好回饋迴圈

### 愈用愈懂你

**技術方向（僅供參考，不限於此）：**

- 偏好建模
- 線上個人化
- Bandits
- 輕量學習
- 將偏好訊號回饋到：
  - 開款
  - 備料
  - 生產

**評分相關重點：**

> 回饋是否能做到「**量化、可驗證**」，是評分重點之一。

---

## 不要只做成 Prompt / 聊天機器人比賽

重點不只是「串一個聊天機器人」，而是把以下三件事做好：

### 1. 可理解

真的聽懂使用者要什麼，包含沒有明說的隱含需求。

### 2. 可解釋

能說明「為什麼」推薦這個結果，而不是黑箱式地直接輸出。

### 3. 可變強

系統愈用愈懂使用者，而且進步必須是**看得見、可被驗證的**。

> **把這三件事做扎實，才是真本事。**

## 一頁式重點整理

這個題目的核心，不只是「用 LLM 幫使用者找衣服」，而是建立一個能夠：

1. **理解需求**：從自然語言中抽取結構化意圖，並處理模糊需求。
2. **做出推薦並解釋**：在商品、搭配、預算等限制下產生有品質且可說明原因的結果。
3. **從回饋中學習**：把使用者偏好量化，形成可驗證的個人化回饋迴圈。
4. **連回製造端**：讓消費者訊號進一步成為設計、開款、備料與生產的市場前端資訊。

評審特別重視：

- 問題洞察與延展性
- 技術深度與創意
- Demo 的完整與可驗證性
- 從問題到解法的表達邏輯
